## ⚙️ Configuración en ZaraRadio

1. Abre **ZaraWeatherSync**.
2. En **Configuración de ZaraRadio**, selecciona la carpeta donde deseas guardar el archivo (por ejemplo `C:\ZaraRadio`).
3. Haz clic en **"Copiar ruta para ZaraRadio"** (o copia la dirección de `clima.txt`).
4. En **ZaraRadio**, abre el menú: **Herramientas > Opciones > Clima**.
5. En el campo **Archivo de clima**, pega la ruta copiada (`Ctrl + V`).
6. Haz clic en **Aceptar**.

¡Listo! Cada vez que ZaraRadio emita la locución horaria o evento de clima, anunciará la temperatura y humedad sincronizadas automáticamente.
